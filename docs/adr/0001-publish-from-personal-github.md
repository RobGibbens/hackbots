# Publish v1 from the personal GitHub account

v1 publishes from `github.com/RobGibbens/hackbots` to `https://robgibbens.github.io/hackbots`, with Astro `site` set to `https://robgibbens.github.io` and `base` set to `/hackbots`. The later home is the team's GitHub organization, `hackbots-3414`. `site` and `base` change at that move. A custom domain is a separate launch decision.

Waiting on the team account would block the shell. Pointing a custom domain at the personal account would add a cutover the shell does not need.
